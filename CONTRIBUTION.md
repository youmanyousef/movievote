# Contributors to Movievote

## Joseph Altareb
- Lead 

Movievote was an idea I had when I thought about the way me and my friends choose movies together on movie nights. We used a ranked-choice voting system, where each friend adds the movies they want to watch to me, I'll give them a list of all the movies and they'd rank them. It was tedious to do this on pen/paper, so thats where the idea of this website comes from.

I picked out the TMDB API to make the movie integration easier for us, and its a very useful tool for querying metadata for said movies. I helped with both the front/back end, but most of my commits relate to how the lobby system works.
